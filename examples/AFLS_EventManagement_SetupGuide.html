0. Confirm the org OOTB

Do not run this in the PNM / IBXQA workspace org. MngEvent is LSC Customer Engagement, API 67.0+.

  1. Setup → Company Information — Life Sciences Cloud and Life Sciences Cloud for Customer Engagement.
  2. Developer Console: SELECT Id FROM MngEvent LIMIT 1. If INVALID_TYPE, stop and use Figma only.
  3. App Launcher — Managed Events (or the LSC app that includes Events).
  4. Object Manager — Managed Event, Managed Event Type, Managed Event Participant.
